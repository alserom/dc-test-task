Тестове завдання на позицію PHP Developer  
Термін виконання 3 робочі дні.

Потрібно розпарсити 3 сторінки з категорії товарів, будь якого інтернет магазину на твій вибір. Дані записати в MySQL та CSV.
Припустимо, що у межах цієї задачі, файлова система працює дуже повільно. Синхронний запис може критично уповільнити систему. Потрібно реалізувати рішення, яке дасть можливість не блокувати потік.
Розробити 1 REST endpoint, який видасть перелік товарів у форматі JSON.

### Що потрібно записати в CSV та MySQL:
- Назву продукту
- Його ціну
- Посилання на зображення
- Посилання на продукт
  
### Вимоги:
- Symfony
- Завдання має бути реалізоване як консольна команда та веб контроллер
- Парсинг HTML повинен відбуватися через XPath
- Для запуску проекту потрібно зробити composer install, та викликати команду
- Проект має бути реалізований в Docker
- Проект розмістити на GitHub
  
### Критерії оцінки:
- Архітектура рішення
- Дотримання принципів SOLID
- Опрацювання помилок (exception)
- Тести не обов'язкові, але будуть перевагою.
